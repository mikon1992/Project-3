# Landing Page: RuangKoding

Proyek landing page statis untuk edukasi web dasar (Tugas Mini Project). 
Dibuat dengan pendekatan minimalis namun tetap modern, menggunakan murni HTML5 & CSS3.

## Fitur Utama & Kriteria Lolos
- **HTML Semantik:** Menggunakan `<header>`, `<main>`, `<section>`, `<article>`, `<nav>`.
- **Flexbox Layout:** Responsif murni dengan `flex-wrap` dan `flex: 1 1 ...` tanpa perlu banyak *media query*.
- **Aksesibilitas (A11y):** Terdapat `alt` pada gambar, state `:focus-visible`, dan label yang jelas (class `sr-only`).
- **Tanpa Framework:** 100% CSS murni tanpa Bootstrap, Tailwind, atau inline style.
- **Responsif:** Aman dari horizontal overflow pada ukuran 320px hingga Desktop.

## Refleksi Pembelajaran
Melalui proyek ini, saya menyadari bahwa dengan CSS modern seperti Flexbox, kita bisa membangun *layout* responsif yang *fluid* dan rapi dengan kode yang jauh lebih singkat dibandingkan menggunakan *media queries* secara berlebihan.
